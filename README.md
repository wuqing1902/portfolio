# Portfolio

## Overview

This repository documents my continuous learning journey across multiple areas of computer science, including Python programming, data analysis, machine learning, and cybersecurity. It serves as a structured collection of technical notes, practical exercises, laboratory work, and hands-on projects completed through self-learning, online courses, and academic study.

Rather than focusing on a single discipline, this portfolio reflects an interdisciplinary approach to computing by integrating software development, data science, artificial intelligence, networking, and information security. Each learning domain contains both conceptual documentation and practical implementations that demonstrate continuous skill development.

As my knowledge expands, this repository will continue to grow with additional topics such as deep learning, cloud computing, bioinformatics, and computational biology.

<br><br><br>

## Objectives

The primary objectives of this portfolio are to:

- Document my continuous learning journey.
- Organize technical knowledge into structured documentation.
- Record practical exercises and laboratory work.
- Develop hands-on programming and analytical skills.
- Demonstrate continuous professional development.
- Build a strong interdisciplinary foundation for future research and industry applications.
