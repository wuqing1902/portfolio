# Cybersecurity

## Overview

This section documents my learning journey in **cybersecurity** through structured coursework, practical laboratories, security investigations, and challenge-based exercises.

The portfolio combines theoretical cybersecurity knowledge with hands-on practice across security operations, network security, Linux system administration, threat analysis, incident response, data protection, vulnerability management, and security risk assessment.

The current learning resources include the **Cisco Cybersecurity** learning program, the **Google Cybersecurity Professional Certificate**, and **OverTheWire** wargames. Each resource contributes a different perspective to my cybersecurity development, ranging from foundational security concepts and organizational defense to practical investigations and command-line based security challenges.

The primary objective of this section is to develop a strong foundation in defensive cybersecurity and security operations while building practical skills that can be applied to entry-level cybersecurity, SOC, and security analysis roles.

## Practical Experience

The cybersecurity portfolio combines structured learning with practical application across different types of security activities.

* **Security Investigation:** Hands-on activities include analyzing network traffic, investigating authentication-related events, examining security alerts, and documenting findings using structured investigation methodologies.

* **System & Network Security:** Practical learning includes Linux administration, file permissions, system hardening, network analysis, wireless security, firewall concepts, and network defense.

* **Risk & Vulnerability Management:** The portfolio includes vulnerability assessment, risk analysis, threat modeling, asset classification, and the application of established security frameworks to evaluate organizational security risks.

* **Incident Response:** Incident response activities cover detection, analysis, containment, eradication, recovery, documentation, and post-incident analysis. These exercises provide exposure to workflows commonly associated with security operations and SOC environments.

* **Security Automation:** Python-based exercises demonstrate how scripting and automation can be used to process security-related data and reduce repetitive operational tasks.

* **Challenge-Based Learning:** OverTheWire exercises provide an additional practical environment for strengthening Linux command-line skills, problem solving, and security-oriented thinking.
