# Cybersecurity

## Overview

This section documents my learning journey in cybersecurity through structured coursework, practical laboratories, and challenge-based exercises.

The materials cover both theoretical knowledge and hands-on experience in defensive security, Linux, networking, security operations, and system administration.

Current learning resources include Cisco Networking Academy, the Google Cybersecurity Professional Certificate, and the OverTheWire wargames.

---

## Learning Objectives

The objectives of this section are to:

- Build a strong foundation in cybersecurity principles.
- Develop practical Linux and networking skills.
- Understand modern security operations and incident response.
- Learn common attack techniques and defensive strategies.
- Apply cybersecurity concepts through practical exercises.
