# Google Cybersecurity Professional Certificate

## Overview

This repository documents my hands-on learning journey through the **Google Cybersecurity Professional Certificate**, with an emphasis on practical cybersecurity operations rather than course completion.

The portfolio contains lab exercises, security investigations, incident response documentation, risk assessments, and automation projects completed throughout the program. Each activity focuses on applying cybersecurity concepts using industry tools, security frameworks, and real-world scenarios.

The primary objective of this repository is to demonstrate practical skills relevant to entry-level Security Operations Center (SOC), Cybersecurity Analyst, and Blue Team roles.

<br><br><br>

## Learning Objectives

Throughout this program, I developed practical experience in:

* Security operations and incident response
* Network traffic analysis
* Linux system administration
* SQL-based security investigations
* Security Information and Event Management (SIEM)
* Risk assessment and vulnerability management
* Threat modeling
* Identity and Access Management (IAM)
* Python automation for security tasks
* Professional security documentation
